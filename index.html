📄 catalog-override.js

Згенеруйте файл catalog-override.js і завантажте його в репозиторій GitHub Pages поруч з index.html. Сайт автоматично підтягне ваші зміни при наступному завантаженні сторінки.

URL сайту: https://lavandaaudit.github.io/alfa_copy_print/
Файл catalog-override.js краще класти в репо сайту (тоді він підвантажується локально — найшвидше). Альтернатива — класти в репо адмінки aa, тоді сайт підтягне через CDN-запит.

🌐 Попередній перегляд

Відкрийте каталог у новій вкладці, щоб побачити, як зміни виглядатимуть на сайті.

⚡ Пряме збереження в GitHub

Налаштуйте токен доступу GitHub, щоб зберігати catalog-override.js напряму в репозиторій з адмінки — без ручного завантаження файлу. Натискаєте «Зберегти в GitHub» → файл комітиться → сайт через 1-2 хв підтягує зміни.

Створіть токен: https://github.com/settings/tokens → Classic-токен зі scope repo, або Fine-grained token з правом Contents: Read and write на репо сайту lavandaaudit/alfa_copy_print.
⚠ Токен зберігається тільки в localStorage вашого браузера. Не комітьте адмінку з токеном у репо.
